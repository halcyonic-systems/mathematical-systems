## Brief 2 — "The ladder" (floor first, then what each adds)

The front page opens with a small FLOOR panel: two dots, one arrow, labeled "a thing → a thing it needs," and two sentences: "All the definitions below share this — almost the definition of a network, with one difference: the arrow is an asserted dependency, not a symmetric connection. Each definition below is this floor plus named additions." Then the existing author cards, RE-ORDERED by commitment (Klir → Bunge → Bertalanffy → Mobus), each card gaining one **adds-strip**: small chips naming what it adds over the floor — Klir: *(nothing — this is the floor)*; Bunge: *+mechanism, +difference-making*; Bertalanffy: *+dynamics, +environment ('72)*; Mobus: *+boundary, +environment, +history, +timescale, +hierarchy*.

- Build: floor panel (inline SVG, two dots one arrow — the talk deck's atom), card reorder, chips from a small curated map (gate: every chip must correspond to a tuple slot or shape feature in the entry).
- Bet: the reader's way in is *accretion* — "graduate to the other definitions" made literal. The page performs the K≅2 result: shared floor visible first, divergence displayed as additions.
- Risk: linear order flattens real structure (Bertalanffy is not "between" Bunge and Mobus; the chain is honest only for Klir→Bunge→Mobus); chips compress qualifying conditions into slot-names.
