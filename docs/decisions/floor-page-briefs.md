# Floor page: three sealed design briefs (2026-08-26)

THEN read the calibration ledger entry (prediction pre-registered before the pick;

## Brief A — The Corridor

**One idea:** the page is a walk down the argument, and the floor figure walks with you.

A linear scroll of five stations (what the floor is → what "depends on" means → shape,
not vocabulary → what the floor is NOT → receipts). The same arrow figure recurs at every
station, accruing annotation as the argument does: bare arrow first, then the convention
legend welds on, then the eight role-player pairs fan out beneath it in their world hues,
then — at the NOT station — the figure *breaks*: the fork that fails
(`free_category_maximality_fails`) drawn in refuted red beside the arrow that holds.
Receipts ride each station as quiet chips at the point of claim.

- **Parity mechanism:** the NOT station is a full station with the corridor's only red
  figure — structurally identical weight to the IS stations.
- **Kinship:** the front page's accretion rail, run as prose; the two pages rhyme.
- **Risk:** reads as an essay — a reader who wants the one fact scrolls; the recurring
  figure must visibly *accrue* or it reads as repetition.

## Brief B — The Ledger

**One idea:** the floor page IS an audit worksheet, because the floor is an audited claim.

One structure: a claims table. ~12 rows in five bands, each row = claim · warrant class ·
receipt pointer (Lean declaration, gate name, or entry). "The shared shape is one arrow" is
a row; "arrows read 'is defined over'" is a row; every NOT is a row *in the same table at
the same weight* — refusals and assertions in one ledger, distinguished only by warrant
chrome. A single compact floor figure sits in the page header as identity, not exposition.

- **Parity mechanism:** by construction — NOT rows are rows; no layout hierarchy exists
  for them to be demoted in.
- **Kinship:** the Compare view's instrument register; the page Cliff would design.
- **Risk:** austere to the point of unwelcoming; the material's invitation quality (the
  authors' own words, the figure) is demoted to chrome; weakest for a first-time reader.

## Brief C — The Instrument

**One idea:** the figure is the page; prose is its caption.

A full-width interactive floor figure leads: the walking arrow large, with a selector that
cycles the eight entries' own role-players into the node labels (world hue follows, shape-
level cases shown honestly as "shape-level (Lean)"), the convention legend permanently
welded beneath — the entry pages' floor figure, promoted to protagonist. Below, two
columns of equal width and weight: **WHAT IT IS** (the claims, each with its receipt chip)
and **WHAT IT IS NOT** (composition-is-not-floor with the failing fork drawn small and
red; the below-shape demands with the separating instance named). Footer: the trust line's
receipts expanded to inspectable pointers.

- **Parity mechanism:** twin columns, equal width, same component vocabulary — IS NOT gets
  the page's most memorable graphic (the broken fork).
- **Kinship:** the entry pages' floor figure; the "read every arrow aloud" discipline made
  into UI.
- **Risk:** the interactive selector is the build's expensive part (a static
  all-eight-fanned variant is the fallback); a figure this prominent must not overclaim —
  the legend and the IS-NOT column are load-bearing, not decoration.
