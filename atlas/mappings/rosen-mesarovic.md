# Mapping 004 — The set-theoretic definition and its critics: Mesarović, Bunge, Rosen

**Verdict: the confrontation between the container view (the system IS the set relation)
and its critics was never staged by the principals usually named — Rosen attacked the
school without citing it, Mesarović never answered anyone — but it WAS staged, once, in
print: Bunge (1979, §1.8) rules the Mesarović-form definition "as popular as [it is]
incorrect," and his reason (a relation is a conceptual object, not a thing) is a precise,
citable disagreement about what kind of object a system is, not about structure.**

**Status: argued, not derived.** No test object yet links the entries (see "A candidate
test object" below). **Graded `MDU`** — model-drafted from the primary texts, the verbatims
located in the registered vault ingests, no human pass yet. A human read of Bunge §1.8 and
Mesarović pp. 6–7 against this document is what would raise it.

## The claim

Stated so it could fail:

> Mesarović's Definition 1.1 (entry 008) identifies the class of systems with the class of
> relations on nonempty abstract sets. Bunge (1979, §1.8 "Concluding Remarks") rules that
> definitional form incorrect for concrete systems — "a system is a binary relation — again
> a conceptual object" — and his own Definition 1.1 (entry 003) requires bonded concrete
> things. The disagreement is about the ontological kind of the definiendum
> (concept vs thing), not about the relational structure, which both sides keep.

It fails if Bunge's machinery elsewhere admits bare relations as concrete systems, or if
Mesarović's text restricts systemhood to some proper subclass of relations.

## The witnesses, in the authors' own words

**Mesarović (entry 008, book p. 11, page-verified):** "A (general) system is a relation on
nonempty (abstract) sets: S ⊂ × {Vᵢ : i ∈ I}." And the ontological rider (p. 7, OCR-reliable
prose): "A system is defined as a set (of a particular kind, i.e., a relation). It stands for
the collection of all appearances of the object of study rather than for the object of study
itself." The container view, stated with its own hedge: the set relation "contains all the
information about the actual 'mechanism' we can legitimately use in the development of a
formal theory."

**Bunge (1979, ch. 1 §1.8, vault ingest lines 507–509):** the three popular definitions are
"as popular as they are incorrect." The first — "a system is a set of interrelated elements —
which is fine for conceptual systems but not for concrete ones since sets, no matter how
structured, are sets, hence concepts not things." The third — "a generalization of the
preceding, namely this: a system is a binary relation — again a conceptual object."

Two precision notes the clash must carry:

1. **Bunge admits conceptual systems** (line 328: "If the components are conceptual, so is
   the system... These are the only system kingdoms we recognize"). So his ruling is not
   "a relation is no system at all" but "a relation is at best a *conceptual* system, and a
   definition that identifies system-in-general with it has mistaken the concept for the
   thing." The clash is sharpest against his *concrete*-system definition (entry 003).
2. **Bunge's first target is Bertalanffy's form** ("a set of elements standing in
   interrelation" — entry 004's very wording), and his second is the black-box I/O schema.
   §1.8 is a standing ruling on the definitional forms of two other catalogued authors,
   not only Mesarović.

## The Rosen layer: the debate that did NOT happen

Rosen 1986 ("Some Comments on Systems and System Theory," IJGS 13(1); reprinted in Facets —
full text in the Klir vault ingest) makes the same attack at the category level: systemhood
is independent of set-ness; GST's difficulties come from "the attempt to treat those
properties of a particular system which depend on its systemhood as if it were simply a part
of the Theory of Sets"; and the cart-before-horse aside — the axiom systems characterising
set-ness are themselves systems.

Verified bibliographic facts:

- Rosen's complete reference list is **five items** — Berlinsky, Cohen, Monod, van der
  Waerden, von Bertalanffy. **Mesarović is never cited**, eleven years after the school's
  flagship, in the community's own journal.
- The scanned chapters of Mesarović 1975 never engage relational biology (M,R-systems in
  print since 1958). No response to Rosen exists.
- **Bunge and Rosen cite the same hostile critic** (Berlinski 1976, *On Systems Analysis*) —
  and neither cites the other.
- Klir is the mediator who canonized both sides without staging the fight: Facets presents
  "the Mesarovic framework" in one chapter, quotes Rosen's thinghood/systemhood passage in
  ch. 1 (the provenance of the census primitives `thinghood`/`systemhood`), and reprints
  Rosen's essay whole.
- The synthesis exists only posthumously and by other hands: Wolkenhauer & Hofmeyr 2007
  (*J. Theor. Biol.* 246:3) compose Rosen's closure to efficient causation with the
  Mesarović–Takahara framework in one abstract cell model.

So the record shows one shot fired (Bunge → the definitional form, 1979), one shot fired
past the target (Rosen → the school unnamed, 1986), and no return fire ever. The
container-vs-model question the three positions define is open, and is carried as a research
question outside this catalogue (Limits program, open square 5: set-relations vs morphisms).

## A candidate test object — deferred, deliberately

"A bare binary relation (a set of ordered pairs)": Mesarović admits it definitionally (the
class of systems *is* the class of relations); Bunge refuses it as a concrete system (a
conceptual object) while admitting it could sit in his conceptual kingdom. This is close to
the test-object bar — Bunge's §1.8 is a ruling in his own voice on exactly this form — but
minting `obj:bare-relation` is **deferred to a human decision**, for one reason: Bunge's
ruling is aimed at a *definition schema*, and Mesarović's admission is *constitutive* rather
than an example he offers. Whether that satisfies "a case an author actually ruled on, never
one invented to make a comparison come out" is a judgment call, not a derivation. (Precedent
either way: `obj:ordered-non-bonding` was minted from an explicit Example block; this one
would be minted from a Concluding-Remarks ruling.)
